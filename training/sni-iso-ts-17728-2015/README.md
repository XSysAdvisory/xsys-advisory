## Cara menggunakan
Buka file Markdown langsung di GitHub. Untuk CSV klik Download raw file, buka di Excel (UTF-8, delimiter koma). Isi persetujuan dan parameter sesuai metode, SOP, risiko serta instruksi lab. Contoh J-2611 (jagung 20 t; lima unit independen) merupakan data simulasi, bukan hasil aktual. Contoh mencatat satu segel rusak sehingga 4 unit valid dan lot tetap HOLD; tidak memalsukan tanda tangan.
Tidak memasukkan teks lengkap standar berhak cipta. Hierarki dan kode dokumen merupakan desain internal. Sebelum pemberlakuan verifikasi naskah resmi SNI, acuan lain, persyaratan lab dan K3; sahkan oleh perusahaan.
