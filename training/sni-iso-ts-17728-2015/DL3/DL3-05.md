# DL3-05 — Pengemasan Pelabelan dan Sampling Report

**Revisi:** 00 | **Status:** Draft pelatihan, belum disahkan | **Pemilik:** QA/QC

Disusun untuk diperiksa oleh QA, laboratorium dan K3. Tanggal efektif: setelah persetujuan. Disusun oleh: ____ ; diperiksa: ____ ; disahkan: ____.

1. Gunakan wadah steril jika disyaratkan, kompatibel dan utuh; identifikasi sebelum pengisian jika memungkinkan.
2. Label: ID, produk, lot/batch/truk, titik/strata, waktu, petugas; tambahkan parameter, massa/volume dan segel sesuai plan.
3. Cocokkan label dengan WP04; tutup rapat, segel bila disyaratkan; catat WP05.
4. Kemasan sekunder memisahkan dan melindungi unit; kemasan luar kuat, kondisi dikendalikan sesuai kebutuhan. Ini model operasional, bukan klasifikasi barang berbahaya.
5. Sampling report/BAPC menghubungkan plan, rekaman aktual, metode, deviasi, jumlah unit dan serah terima. WP04–WP06 dapat digunakan sebagai satu paket BAPC. Tidak membuat data atau paraf fiktif.
