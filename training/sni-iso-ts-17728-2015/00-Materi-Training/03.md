# Modul 03 — Persiapan bahan, alat, personel dan K3

Durasi usulan: 20 menit | Draft pelatihan | Kasus fiktif J-2611

**Siapkan bahan simulasi aman, tanpa kultur patogen hidup atau mesin aktif.**
| Kelompok | Bahan/alat | Contoh kebutuhan J-2611 | Verifikasi |
|---|---|---|---|
| Bahan | Jagung kering peraga | Cukup untuk 5 unit + cadangan | Aman, teridentifikasi |
| Sampler | Scoop atau probe yang sesuai | 5 set steril, atau pengendalian carry-over yang tervalidasi | Utuh, bersih, sesuai metode, bukti pelepasan |
| Wadah | Kantong steril kering | 5 + cadangan | Segel/pembungkus utuh |
| Ukur | Neraca dan wadah tertara | 1 set | Bersih, terkendali, hindari kontaminasi |
| Identitas | Label, marker, segel | 5 + cadangan | ID U01–U05, S-101–105 |
| Transport | Sekunder dan luar, monitor jika perlu | 1 set | Sesuai kondisi lab |
| Personel | APD sesuai risiko, higiene tangan | Per petugas | Kompetensi dan akses aman |
| Dokumen | WP01–09 dan checklist | 1 set | Tersedia sebelum sampling |
**Urutan:** cek plan → otorisasi PPC → briefing K3 → kebersihan tangan/APD → periksa sterilitas alat sesuai metode → wadah → label → transport → WP03. Gunakan siklus sterilisasi alat reusable yang tervalidasi; alkohol bukan pengganti sterilisasi. Larang api terbuka di area debu pakan. Jangan akses bagian bergerak, truk/silo/ketinggian tanpa izin dan pengendalian. STOP/HOLD jika salah satu prasyarat kritis tidak memenuhi; koreksi dan verifikasi ulang.
**Demo:** trainer menunjukkan cara membuka wadah steril tanpa menyentuh sisi dalam, melindungi bagian kontak alat, dan mengganti alat/sarung tangan sesuai risiko.
