# Catatan validasi manual sumber
Dua teks lampiran identik; digunakan satu manual sebagai dasar. Paket merupakan adaptasi pelatihan, bukan salinan standar SNI atau SOP De Heus.

| Aspek manual sumber | Pengendalian sebelum adopsi |
|---|---|
| 5 titik dan komposit 250–500 g; akar jumlah karung; 3 waktu outgoing | Validasi terhadap tujuan, protokol statistik, metode dan ukuran lot. Unit independen tidak boleh dicampur tanpa izin. |
| 15–25°C kering; 1–8°C basah; 24/36 jam | Tetapkan sesuai matriks, metode dan instruksi lab; bukan angka universal. |
| Siklus autoklaf/oven | Validasi siklus, beban, kompatibilitas alat dan pelepasan; jangan mengandalkan setpoint saja. |
| 1 alat per lot; alkohol 70% | Cegah carry-over antar unit independen. Alkohol tidak menjamin sterilitas; kendalikan kebakaran/debu. |
| Akses truk/silo/port, uap panas | K3 menyetujui titik dan sistem akses; jangan membuka guard/mesin aktif, jangan membuka sampel panas tanpa metode tervalidasi. |
| Penolakan otomatis karena deviasi | Evaluasi bukti dan dampak sesuai SOP lab, konsultasi terdokumentasi. |
| ISO 6497, ISO/TS 22002-6, Permentan 22/2017 | Acuan tercantum pada sumber; cek status dan keberlakuannya. |

Acuan untuk verifikasi: [ISO/TS 17728:2015](https://www.iso.org/standard/60322.html), [ISO/IEC 17025:2017](https://www.iso.org/standard/66912.html), katalog BSN dan regulasi resmi yang berlaku. Naskah lengkap SNI tidak disertakan dan belum diaudit klausul per klausul. Tidak ada data aktual perusahaan, nama peserta atau tanda tangan nyata.
