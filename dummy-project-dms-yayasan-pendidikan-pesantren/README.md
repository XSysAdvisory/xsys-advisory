# Dummy Project DMS Yayasan Pendidikan & Pesantren

**XSys•SmartDMS — Education & Pesantren Edition**

[Demo aplikasi](https://xsysadvisory.github.io/xsys-advisory/smartdms-pesantren.html) · [Source code](../smartdms-pesantren.html)

Prototipe pengendalian dokumen yayasan pendidikan dan pesantren: Create, Review, Approve, Publish, Revision, Obsolete, pencarian metadata, periodic review, dan audit trail.

Data fiktif, penyimpanan lokal browser; belum terhubung ke Google Sheets/Drive dan belum memiliki autentikasi produksi.
