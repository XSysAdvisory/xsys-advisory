# Post-test — 15 pertanyaan

Pilih satu jawaban pada setiap soal.

Lampiran — POST-TEST (15 pertanyaan)
Jawab melalui aplikasi interaktif untuk skor dan pembahasan otomatis.
1. Eyewash tersedia di koridor tetapi inspeksi fungsinya tidak ada. Kesimpulan audit?
1. Kontrol pasti efektif
2. Tidak perlu dicatat
3. Efektivitas belum terbukti; lakukan verifikasi sesuai risiko
4. Cukup pasang label
2. Autoklaf memiliki keluhan uap mendadak dan gasket belum ditindaklanjuti. Keputusan tepat?
1. Lanjutkan dengan lebih hati-hati
2. Hentikan/batasi penggunaan dan verifikasi perbaikan/kelaikan
3. Cukup menambah poster
4. Buka pintu segera
3. Bila L awal 4 dan S awal 4, skor awal =…
1. 4
2. 8
3. 12
4. 16
4. Perubahan SOP setelah temuan baru boleh ditutup sebagai CAPA ketika…
1. File diunggah
2. Form ditandatangani
3. Tindakan telah efektif dan ada bukti verifikasi
4. Uang dibelanjakan
5. Limbah cair tanpa identitas lengkap ditemukan dekat sharps hampir penuh. Tindakan awal?
1. Campurkan semua agar ringkas
2. Isolasi aman, identifikasi, ganti wadah sharps dan eskalasi
3. Buang ke saluran air
4. Biarkan untuk shift berikutnya
6. Peran utama legal applicability assessment adalah…
1. Mewajibkan semua regulasi di daftar
2. Menentukan aturan yang berlaku beserta dasar, PIC dan buktinya
3. Membuat logo lembaga
4. Menggantikan izin
7. Regulasi OSHA 29 CFR 1910.1450 untuk laboratorium Indonesia…
1. Otomatis hukum Indonesia
2. Tidak boleh dirujuk
3. Acuan teknis benchmark; keberlakuan hukum bergantung yurisdiksi
4. Menghapus UU 1/1970
8. Risiko kekurangan oksigen dari bocoran N2 perlu dikaji berdasarkan…
1. Hanya warna tabung
2. Volume/tekanan, kebocoran potensial, ventilasi, konfigurasi ruangan
3. Jenis seragam
4. Jumlah pengunjung situs
9. Temuan audit: karyawan mengenal SOP, tetapi praktik bertentangan. Bukti harus…
1. Mengikuti SOP saja
2. Mengikuti wawancara saja
3. Mencatat fakta observasi dan kriteria relevan
4. Dihapus agar nilai baik
10. Saat terjadi tumpahan tidak diketahui komposisinya, respons paling tepat…
1. Mencampur bahan penetral sembarang
2. Menyerahkan pada petugas terlatih sesuai SOP setelah pengamanan area
3. Membersihkan tanpa APD
4. Mencium bahan untuk identifikasi
11. Bukti objektif sistem pelatihan kompetensi paling kuat…
1. Foto bersama
2. Daftar hadir saja
3. Observasi keterampilan, otorisasi, catatan evaluasi dan refresher
4. Poster ruangan
12. Sebelum menurunkan nilai likelihood sebagai residual risk, harus tersedia…
1. Harapan manajemen
2. Kontrol yang diterapkan dan diverifikasi
3. Hanya anggaran
4. Warna matriks
13. Seorang auditor memberi N/A pada persyaratan. Ia perlu…
1. Tidak perlu alasan
2. Alasan dan bukti tidak berlakunya ketentuan
3. Menghentikan audit keseluruhan
4. Menilai skor penuh
14. Tujuan management review LSMS adalah…
1. Memajang sertifikat
2. Menentukan keputusan sumber daya dan perbaikan berbasis data
3. Mengulangi semua quiz
4. Menghindari inspeksi
15. Rangkaian yang paling lengkap adalah…
1. SOP → arsip
2. Bahaya → risiko → kontrol → uji efektivitas → audit → CAPA
3. APD → foto
4. Temuan → tanda tangan
