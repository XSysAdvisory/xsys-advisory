# Pre-test — 15 pertanyaan

Pilih satu jawaban pada setiap soal.

Lampiran — PRE-TEST (15 pertanyaan)
Jawab melalui aplikasi interaktif untuk skor dan pembahasan otomatis.
1. Apa tujuan utama LSMS?
1. Mengganti semua standar mutu
2. Mengelola risiko kerja lab secara sistematis
3. Meniadakan supervisi
4. Mengurangi pencatatan
2. Dalam RAMP, huruf P berarti…
1. Perform testing
2. Prevent exposure
3. Prepare for emergencies
4. Publish results
3. Pengendalian yang paling tinggi dalam hierarki adalah…
1. APD
2. Administratif
3. Rekayasa teknik
4. Eliminasi
4. Jika SDS tidak tersedia, tindakan paling tepat adalah…
1. Menebak berdasarkan warna
2. Menunda aktivitas yang memerlukan informasi tersebut dan memverifikasi SDS
3. Memakai sarung tangan seadanya
4. Mengabaikannya
5. Pelarut dipindahkan di dekat hotplate yang baru digunakan. Prioritas awal?
1. Periksa/isolasi sumber penyalaan dan hentikan transfer tidak aman
2. Tambah volume transfer
3. Ganti botol dengan yang lebih kecil saja
4. Buka tutup lebih lama
6. Sebuah tabung gas nitrogen tanpa pengikat tetap terutama menimbulkan risiko…
1. Kerusakan label saja
2. Jatuh dan pelepasan tekanan
3. Kelembapan
4. Korosi logam semata
7. Skor risiko dengan L=3 dan S=4 adalah…
1. 7
2. 12
3. 1
4. 34
8. Apa arti “risiko sisa proyeksi”?
1. Risiko sudah terbukti rendah
2. Tidak ada bahaya
3. Perkiraan sebelum uji efektivitas kontrol
4. Pekerjaan pasti boleh dilanjutkan
9. APD untuk pekerjaan HCl sebaiknya…
1. Selalu cukup dengan kacamata biasa
2. Dipilih berdasarkan SDS dan penilaian pekerjaan
3. Tidak diperlukan jika ada meja
4. Dipilih berdasarkan warna
10. BSC dan clean bench…
1. Selalu sama
2. Hanya berbeda bentuk
3. Harus dinilai menurut fungsi perlindungan; tidak ekuivalen
4. Tidak perlu sertifikasi
11. Saat sentrifus bergetar tidak wajar, operator harus…
1. Menaikkan kecepatan
2. Melanjutkan sampai selesai
3. Menghentikan penggunaan sesuai SOP dan meminta pemeriksaan
4. Membuka saat berputar
12. Temuan audit dinyatakan memenuhi bila…
1. Ada rencana membeli alat
2. Wawancara saja
3. Dokumen dan bukti implementasi sesuai kriteria
4. Supervisor mengatakan aman
13. PP No. 50/2012 tentang SMK3 mewajibkan penerapan pada…
1. Semua laboratorium tanpa kecuali
2. Perusahaan ≥100 pekerja atau berpotensi bahaya tinggi
3. Hanya laboratorium sekolah
4. Hanya perusahaan eksportir
14. Penyimpanan bahan kimia paling tepat dikelompokkan berdasarkan…
1. Abjad saja
2. Harga
3. Kompatibilitas dan bahaya berdasar SDS
4. Ukuran font label
15. Apa keluaran penting dari simulasi darurat?
1. Foto kegiatan saja
2. Bukti uji kesiapan, gap dan tindakan perbaikan
3. Jumlah peserta saja
4. Peta ruangan saja
